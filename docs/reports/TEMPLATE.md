# <Topic>

- **Date:** YYYY-MM-DD
- **Requested by / context:** who asked, or what triggered this (an incident, a question, a hunch)
- **Status:** Open / Resolved / Superseded by [\<other report\>](./other-report.md) / Rejected

## Context

What prompted this — the question being answered, the symptom being investigated, the scope.

## Findings

What was actually found. Be concrete: file paths, line numbers, commands run, evidence — not just
conclusions. A reader should be able to verify each claim.

## Recommendation

What should happen as a result, if anything. Separate "must do" from "could do".

## Outcome

Fill in later (or leave as `Not yet acted on`) once a recommendation is implemented, rejected, or overtaken by
events. Link to the commit/PR/follow-up report where relevant. See
[docs/reports/README.md](./README.md#reports-are-frozen-in-time--dont-edit-them-later) — update this section,
don't rewrite Findings.
