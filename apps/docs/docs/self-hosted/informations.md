# Information

So you want to self-host gmod-integration ? Great! This page will guide you through the necessary steps to set up your own instance of the documentation and website.

There a 2 way to run gmod-integration, in production or in development.

For production see [install docs](/self-hosted/install-prod) and for development go directly to ['gmod-integration-monorepo' README](https://github.com/gmod-integration/gmod-integration-monorepo)
