# /rewards

View your rewards for a game server, the required conditions, your recorded playtime and delivery status.
The response is private. Link your Steam and Discord accounts first.

```text
/rewards server:<server> page:<number>
```

The server is required; the page number is optional. Only servers belonging to the current Discord
community can be selected. Automatic rewards require no claim action. In-game rewards wait for your
next connection until their delivery deadline, and manual rewards are attributed by the server staff.

If an outcome needs review, ask the server staff to inspect the Rewards history before issuing anything again.
